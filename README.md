# Digital Travel Journal Local Storage

This example demonstrates a basic digital travel journal application using HTML and JavaScript. It allows users to create journal entries with text and an optional image, storing them persistently in the browser's `localStorage`. The application showcases how to capture and display user-generated content, including multimedia, within a client-side web environment.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in your web browser.
3. Enter your journal entry and optionally select an image, then click "Giriş Ekle" (Add Entry).
